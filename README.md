# Closet — Fashion Resale App

Fashion resale marketplace app in an interactive phone frame.

**[Live Demo](https://shaisolaris.github.io/flutter-closet/)**

## Features

- **Feed** — six listings with category filters, like buttons with live counts and seller notification
- **Item detail** — retail-vs-resale pricing, size/condition/protection chips, seller profile with rating and sales
- **Offer flow** — quick-pick offer amounts computed from the asking price (80% / 90% / near-ask), 24-hour expiry
- **Buy now** — instant order with tracked shipping confirmation
- **Sell flow** — title/price/condition form with a market pricing tip; new listings go live in "Your listings"

## Structure

Single self-contained page: Flutter-style mobile patterns in pure HTML/CSS/JS. No frameworks, no build step.
